## Practical recommendation

To keep the taxonomy consistent, these are the most important labels to prioritise across the Vikkypaedia repositories:

1. medical-education
2. self-directed-learning
3. self-paced-learning
4. open-educational-resources
5. mooc
6. pediatric-care
7. neonatal-care
8. competency-based-medical-education
9. offline-first
10. evidence-based-medicine

These terms align with the project's academic, learner-centred, and mobile/offline-first design philosophy.

## Mapping to GitHub Topics

GitHub Topics are the best-fit mechanism to reflect these domains. The canonical terms above can be applied directly in each repository's Settings > Topics, while this file acts as the shared source-of-truth for consistency across the portfolio.
